# VIRKAN Roadmap

## v2.1 — Refactor & stability

- Разделить игровой код на модули без изменения механик.
- Вынести CSS и JavaScript из монолитного HTML.
- Добавить автоматические smoke-тесты основных состояний UI.
- Упростить обновление версии одновременно для Web и Android.
- Усилить обработку сохранений и миграций между версиями.

## v2.2 — Content

- Новые районы города и уникальные ориентиры.
- Больше сюжетных миссий и случайных событий.
- Расширение поведения NPC и транспорта.
- Новые противники и разновидности оружия.

## v2.3 — Android release preparation

- Release signing через GitHub Secrets.
- Android App Bundle (`.aab`).
- Иконки adaptive launcher во всех размерах.
- Экран загрузки и оптимизация запуска.
- Финальное тестирование на нескольких Android-устройствах.
